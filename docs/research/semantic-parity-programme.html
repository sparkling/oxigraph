01 · Decision

Two tranches, one standards authority.

Jena supplies production-shaped differential cases. W3C supplies the terminal semantic contract. Their results stay separate so matching Jena can never hide a newer draft requirement.

TRANCHE A

jena-12-compat

Match RDF, SPARQL, SHACL, entailment, and OWL 2 RL intersection cases exposed by the pinned Jena release. Jena OWL modes stay test-only.

TRANCHE B

W3C 1.2 family profiles

Close Jena’s gaps against complete RDF, SPARQL, and SHACL document families, requirement ledgers, and approved official tests.

AUTHORITY

W3C wins conflicts

Reviewed W3C snapshots govern release claims; current editor drafts run in a separate edge lane. Jena remains a differential oracle.

02 · Architecture

One evidence path from graph to receipt.

The base dataset remains immutable during evaluation. Derived facts and SHACL reports are distinct outputs, joined only by an explicit query view or caller-selected materialization.

Earliest corruptible phase: rule/shape validation, before evaluation or allocation-heavy work. Integration seam: spareval::QueryableDataset.
03 · Engine choice

Own the rule contract; benchmark the evaluator.

No evaluated Rust crate supplies runtime user rules, RDF integration, safety, provenance, and Oxigraph’s deployment envelope as one package.

Recommended

Public Oxigraph IR, internal evaluator trait.

  • OxDatalog D0–D2 passes 70/70 native tests: positive recursion, stratified negation, and bounded run-once generation.
  • The complete mutation inventory generated 358 mutants: 278 caught, 80 unviable, zero missed, and zero timed out.
  • Oxigraph's rdfs feature always selects the 15-pattern RDF 1.2 finite profile; the separate 14-pattern Basic profile is available only through direct oxrdfs use without rdf-12.
  • Datafrog stays test-only; Jena 6.1.0 differentials pass for Datalog and finite RDFS, while Soufflé 2.5 agrees on the safe D1 path fixture.
  • OWL 2 RL/RDF remains in oxowl: 78 rules (46 Datalog rules, 32 specialized operators) pass 98/98 assertions over 68 approved RDF-based cases.
  • SHACL semantics stay in oxshacl; inferred and report graphs remain separate from the immutable base snapshot.

Not selected directly

Each is useful, but incomplete for this boundary.

  • Ascent/Crepe: primarily compile-time macro programs.
  • Soufflé: mature, but a C++ production dependency.
  • Cozo: overlaps Oxigraph storage and query responsibilities.

08 · Receipt

The bounded baseline has a fail-closed acceptance contract.

A parity result is accepted only when a current schema-v5, run-addressed receipt is complete, set- and order-equal to the reviewed inventory, and independently verified. Acceptance does not prove broad Jena parity, RDF/SPARQL/SHACL 1.2 family parity, unrestricted RDFS entailment, or any OWL profile beyond the declared OWL 2 RL/RDF surface. The prior reconciliation keeps the refreshed Jena, 144/129 CLI, then-34-test persistence-write, and generic OxDatalog identities historical for their scoped subjects. Current schema-v5 adapter, persistence, and G1 receipts cover 40, 45, and 66 tests at 5a93890f and were independently reopened. Their dirty bit reflects protected untracked runtime paths. This is scoped evidence; no aggregate Agentic/MetaHarness qualification or G1.7 promotion follows.
