Bounded semantic parity over Oxigraph

This site documents the extension in this fork. Upstream Oxigraph remains the RDF graph database and toolkit foundation; the fork adds version-pinned RDF 1.2, SPARQL 1.2, Datalog, RDFS, OWL 2 RL/RDF, SHACL, and qualification profiles.

The extension is explicitly bounded. It does not claim full Apache Jena portfolio compatibility or blanket conformance to every RDF, SPARQL, or SHACL family obligation.
